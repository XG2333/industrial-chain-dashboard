# 通用进出口配对与净出口计算规则

本规则适用于锂电、锡、硅所有产业链，统一解决进出口数据“对应不上”和缺失净出口的问题。

规则实现位置：

- `scripts/import_export_rules.py`：配对、净出口计算、选中去重
- `scripts/calculate_net_exports.py`：通用净出口计算 CLI
- `scripts/apply_industry_selection.py`：所有产业统一执行进出口配对去重

## 规则内容

1. 进出口只保留月度总量指标。
2. 只保留同时存在进口和出口的指标。
3. 同一产品/来源/统计口径/单位维度下，进口量与出口量一一对应；配对可跨 Sheet，但不得跨来源、产品、统计口径或单位维度。
4. 分国别、分规格、均价、金额类和非总量数据不参与净出口计算，也不因配对而误选。
5. 只有进口没有出口的指标，直接筛除；只有出口没有进口的指标，同样直接筛除；其对应的净出口行也必须一并筛除。
6. 缺失净出口时，将进口、出口按日期对齐，生成：

```text
净出口 = 出口 - 进口
```

7. 计算结果写入 `净出口计算` Sheet，并追加到目录 Sheet：

```text
大类：原进口/出口指标的大类
子类：净出口
数据性质：流量
是否选中：是
状态说明：确定性净出口计算
```

8. 如果同一口径存在多条进口或出口，只保留一条总量，其余不选中。
9. 已存在净出口但没有对应进口和出口配对的，同样不保留。

## 口径处理细则

1. 标题以“月度”结尾时按月度处理，优先于目录 Sheet 中可能写错的“日度/周度”等频率。
2. 分国别、分省份 Sheet 中的“总计/合计/总量”行同样参与配对，不因 Sheet 名称包含“分国别”而误排除。
3. 进口与出口可以位于不同 Sheet，但必须属于同一来源、产品、统计口径和数量维度。
4. `进口量` 只与 `出口量` 配对；`进口额`、`出口额`、`净出口额`、`金额` 等金额类进出口不保留，也不参与配对。
5. 均价、平均价、价格类进出口不选中，也不参与净出口计算。
6. 同一口径存在多条进口或出口时，优先保留子类明确为“进口”或“出口”的行，避免误保留“进出口”聚合行。
7. 重复净出口只保留一条，其余不选中。
8. `中国金属锂/金属锂`、`日本海关/本海关` 等因前缀或频率词导致的写法差异，按统一口径归一后配对。
## 数量平衡硬校验

进出口总量标题可能写作 `进口量/出口量`，也可能直接写作
`进口/出口/净出口`。最终产业筛选必须处理全部目录行，不能只依赖 Skill2
预先选中的结果；只要同一口径存在月度进口和出口，就应保留进口、出口以及
对应净出口，并筛除其余重复或聚合行。

每次 `apply_industry_selection.py` 保存前必须校验：`进出口` 大类下
`进口`、`出口`、`净出口` 三个子类的选中数量必须相等，否则流程直接失败。

标题中以 `_国家/地区` 出现的国别明细、海外精炼锡等来源明细不参与配对；不带来源前缀的存量净出口行可继承同口径进口/出口的来源完成配对。

金额类指标即使按分类规则归为 `价格 / 贸易金额`，仍按本规则直接筛除，不因分类变化而恢复选中。

## 前端展示同步

- 看板前端不把“进出口”拆成“进口、出口、净出口”三个子类按钮。
- 同一指标的进口、出口、净出口图合并为一行，行内顺序固定为：进口 -> 出口 -> 净出口。
- 目录行排序仍按 Excel 子类顺序执行；前端展示归组由 `industryGroups.ts` / `chartGrouping.ts` 完成。
