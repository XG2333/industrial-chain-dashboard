# 锡产业链指标标签规则

规则实现位置：`scripts/tin_rules.py`

使用位置：`scripts/apply_tin_curation.py` 的“指标标签”JSON 生成。

## 产品识别

按顺序匹配“指标名称 + Sheet 名称”，命中即返回产品：

| 产品 | 关键词 |
|---|---|
| 锡矿 | 锡矿、锡精矿、矿砂、精矿 |
| 锡锭 | 锡锭、锡碇、精炼锡、精锡、未锻轧、1#锡、1号锡、沪锡、LME锡、锡库存、锡仓单 |
| 锡材 | 焊料、焊锡、锡条、锡丝、锡粉、锡合金、巴氏合金、锡材、锡制品 |
| 镀锡板 | 镀锡板、马口铁 |
| 铅蓄电池 | 铅蓄电池、电蓄、汽蓄、摩托、蓄电池 |
| 锡化工 | 二氧化锡、锡酸钠、氯化亚锡、硫酸亚锡、锡化工、氧化锡 |
| 光伏焊带 | 光伏焊带、MBB、焊带 |
| 锡期货 | 期货、合约、仓单、JFX、ICDX |

未命中时回退到目录“板块”，板块仍为空则回退到“锡产业链”。

## 指标类型

优先从名称匹配：

- `成交持仓比`：含“成交持仓比”
- `成交量`：含“成交量”
- `持仓量`：含“持仓量”
- `基差`：含“基差、期现、升贴水”（子类归入 `价差`）
- `价差`：含“价差、溢价”（子类归入 `价差`）

否则回退到子类；子类为“其他”时回退到大类；仍为“其他”则返回“其他”。

## 规格抽取

正则优先：

- `数字V/数字AH`，例如 `48V/12AH`
- `数字AH`
- `数字%`，例如 `40%`、`36.5%`
- `数字#`，例如 `1#`
- `数字A`，例如 `63A`
- `数字mm`
- `TLEAD/TPURE` 合约代码
- `SAC`

词表：驰名、大型、中型、小型、电动、起动、牵引、固定、无铅、有铅、精矿、粗锡。

无命中时返回“通用”。

## 工艺属性

词表匹配：精炼、粗炼、再生、原生、冶炼、火法、湿法、电解、采选、进口矿、国产矿、自产矿、外采矿。

无命中时返回“通用”。

## 地域

优先匹配中国省份/港口/洲别，再匹配国家/地区词表。

无命中时返回“未指定”。

## 统计口径

词表匹配：平均价、最低价、最高价、收盘价、结算价、开盘价、成交量、持仓量、成交持仓比、库存量、库存变化、显性库存、注册仓单、注销仓单、仓单日报、分仓库、分地区、分国别、分洲别、分企业、分类型、总计、合计、总量、累计、净出口、净进口、小计、预测、计划、累计值、当月合约、主力合约。

无命中时返回“未指定”。

## 状态

- 含“预测、计划、目标、预算、估算、下月预计”时返回对应词
- 默认返回“实际”
