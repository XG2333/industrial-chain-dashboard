# 锡产业链目录板块分类规则

规则实现位置：`scripts/tin_rules.py`

使用位置：`scripts/tin_catalog.py` 的 Skill1 目录生成。

| 板块 | 关键词 |
|---|---|
| 锡矿 | 锡矿、锡精矿、矿砂、精矿、矿山、锡矿砂、马来西亚进口 |

| 锡材 | 焊料、焊锡、锡条、锡丝、锡粉、锡合金、巴氏合金、锡材、锡制品 |
| 镀锡板 | 镀锡板、马口铁 |
| 铅蓄电池 | 铅蓄电池、电蓄、汽蓄、摩托、蓄电池 |

## 判定方式

按表顺序逐项匹配 Sheet 名称，命中即返回对应板块；全部未命中返回“其他”。

## 频率判定

Sheet 名称包含“日/周/月/季/年”时，分别映射为日度、周度、月度、季度、年度；无命中时默认年度。

指标名称同时出现 `年化` 与 `日度/周度/月度/季度/年度` 等多个频率词时，按实际数据频率处理，
含 `年化` 且带其他频率后缀的指标归为年度。

## 目录生成要求

第一个 sheet 若已经是目录（A1 为 `#`），则在原 sheet 更新；否则新建 `指标目录` sheet 插入到最前面，不能覆盖原始数据 sheet。
