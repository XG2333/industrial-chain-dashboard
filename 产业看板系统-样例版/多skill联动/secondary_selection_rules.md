# 二次筛选规则

## 定位

`scripts/apply_industry_selection.py` 写入"是否选中"（第一次筛选，是/否）后，
追加计算"二次筛选是否保留"列（是/否）。**二次筛选不修改"是否选中"**，
只作为展示性筛选列，供后续按需取数使用。

- 新增列位于目录表最右侧（"指标标签"之后），列名 `二次筛选是否保留`
- 仅第一次筛选为"是"的行进入二次筛选判定；第一次为"否"的行二次筛选一律为"否"
- 补算成交持仓比行（`scripts/volume_position_ratio.py`）同样计算并写入该列

## 判定规则（按顺序判定，命中即止）

| 顺序 | 条件 | 结果 | 说明 |
|---|---|---|---|
| 1 | 是否选中 = 否 | 否 | 不进入二次筛选 |
| 2 | 频率 ∉ {日度, 周度} | 否 | 月度、半月度、季度、年度数据全部删去 |
| 3 | 标题含 `指数` | 否 | 指数类指标全部筛除；但含 `库存周期指数` 或 `库存天数` 的指标除外（如"碳酸锂库存周期指数: 分环节库存天数"——"库存周期指数"是 SMM 对库存天数指标的命名方式，实质是库存天数，不算指数） |
| 3b | 标题含 `情绪因子` | 否 | 情绪因子类指标全部筛除（如"磷酸铁出货/成交/购货情绪因子"） |
| 3c | 标题含 `修复` | 否 | 修复型相关指标全部筛除（如"修复型磷酸铁锂"），优先于板块保留词 |
| 4 | 板块 ∈ {负极材料, 隔膜, 辅材, 新能源汽车} | 否 | 锂电下游板块整板块筛除 |
| 5 | 板块专属保留词 | 见下表 | 标题必须含保留词才保留 |
| 5b | 板块专属排除词 | 见下表 | 标题含排除词即不保留，其余保留 |
| 6 | 锂盐板块 | 碳酸锂/氢氧化锂整板块保留；其他锂盐整板块筛除 | 月差、基差等标题无产品名的碳酸锂期货指标同样保留 |
| 7 | 其余板块 | 是 | 仅受规则 1-3 约束 |

### 板块专属保留词

| 板块 | 保留词（标题含任一即保留） |
|---|---|
| 磷酸铁锂 | 磷酸铁、磷酸铁锂、磷酸锰铁锂（LMFP 属磷酸铁锂家族） |
| 磷化工链 | 磷酸铁、磷酸铁锂、磷酸锰铁锂（磷化工链归入磷酸铁锂板块规则：磷矿、磷酸、热法磷酸、磷酸一铵等一律不保留） |
| 三元正极 | 三元前驱体、三元材料 |
| 电解液产业链 | 电解液、六氟磷酸锂 |

碳酸锂 / 氢氧化锂板块为**整板块保留**（不要求标题含产品名）；其他锂盐板块整板块筛除。

### 板块专属排除词

| 板块 | 排除词（标题含任一即不保留） | 说明 |
|---|---|---|
| 锂矿 | 原矿 | 锂矿部分只保留精矿：**指标名称中不带"原矿"的都是精矿**（即使指标未写"精矿"二字，但实际就是精矿），因此仅排除标题含"原矿"的指标，其余保留 |
| 磷酸铁锂 | 储能型压实密度≥2.30g/cm³、动力型压实密度≥2.50g/cm³ | 仅排除这两个规格的平均价指标（周度版本，如"SMM: 磷酸铁锂 (储能型压实密度≥2.30g/cm³)-平均价: 周度"）；同板块其他压实密度规格（粉体压实密度、储能型 2.40/2.50 日度等）不受影响。排除词优先于板块保留词判定 |

### 未提及板块

储能、电池电芯、磷化工链、锰酸锂、钴酸锂等板块未列入专属规则，
仅受频率（规则 2）与指数（规则 3）约束，日度/周度非指数指标保留。

## 锡/硅通用规则（secondary_selection_decision_generic）

锡、硅数据暂无板块保留词/排除词等专属规则，仅受通用约束
（`scripts/secondary_selection.py` 的 `secondary_selection_decision_generic`）：

1. 未选中（是否选中=否）→ 否
2. 频率 ∉ {日度, 周度} → 否
3. 标题含"指数"（含"库存周期指数/库存天数"例外的除外）→ 否
4. 其余 → 是

执行：`scripts/recompute_secondary_tin_silicon.py` 对
`本地可视化dashboard/data/锡产业链数据_workflow_ai.xlsx` 与
`硅产业链数据_workflow_ai.xlsx` 写入"二次筛选是否保留"列（列不存在时追加到最右，
处理前自动备份）。当前保留数：锡 130、硅 692（2026-08-28）。

## 执行位置

- `scripts/secondary_selection.py`：规则实现（`secondary_selection_decision` /
  `apply_secondary_selection` / `secondary_selection_decision_generic`）
- `scripts/apply_industry_selection.py`：调用并写入列
- `scripts/volume_position_ratio.py`：补算成交持仓比行写入同一列
- `scripts/recompute_secondary_tin_silicon.py`：锡/硅通用规则写入列
- 规则文档：本文件
