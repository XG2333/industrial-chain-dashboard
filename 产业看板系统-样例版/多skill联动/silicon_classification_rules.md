# 硅产业链分类规则

## 用途

本文件用于确定目录 Sheet 中每条指标的大类和子类。当前实现已接入通用
候选机制 `scripts/classification_candidates.py`：

1. 指标名称
2. 所在 Sheet 名称（仅在指标名称未命中时回退）
3. 单位作为 AI 消歧时的辅助依据

不再使用“命中即停止”的关键词优先级；唯一候选直接采用。价格大类多个
子类候选按确定性优先级直接确定：`成交持仓比 > 成交量 > 持仓 > 月差 >
现货价差 > 期货价格 > 现货价格`。其他大类多个候选仍写入
`候选大类` / `候选子类` / `候选分类组合`，由 AI 结合名称、Sheet、单位和
频率消歧。通用说明见
[classification_candidates_rules.md](classification_candidates_rules.md)。

分类只决定 `大类` 和 `子类`，不决定 `是否选中`。是否选中由筛选规则单独决定。

## 判定顺序

### 1. 库存类优先

- 名称含 `库存指数`：`库存 / 库存指数`
- 名称含 `库存天数`：`库存 / 库存天数`
- 名称含 `仓单`：`库存 / 仓单`
- 名称含 `库存` 且不是 `进口量/出口量/净出口`：`库存 / 库存`

示例：

- `SMM: 原生铝合金产品库存指数`：`库存 / 库存指数`
- `SMM: 进口高纯石英砂成品库存`：`库存 / 库存`

### 2. 成本利润类

- 名称含 `成本/LCOE/折旧/人工/三费/投资/运维/电耗/水耗/能耗/耗量/消耗/浆料/银浆` 等：`成本利润 / 成本`
- 名称含 `利润/盈亏`：`成本利润 / 利润`
- 位于成本模型 Sheet 中且单位是价格单位：优先归 `成本利润 / 成本`

示例：

- `SMM: 光伏胶膜成本模型: 折旧-EVA420g`：`成本利润 / 成本`
- `SMM: 硅片利润-N183`：`成本利润 / 利润`

### 3. 价格类

- 名称含 `成交量`：`价格 / 成交量`
- 期货收盘价、合约价格：`价格 / 期货价格`
- 基差、期现价差：`价格 / 现货价差`（基差保留在指标标签的“指标类型”中）
- 月差：`价格 / 月差`
- 现货价差：`价格 / 现货价差`
- 成交量：`价格 / 成交量`
- 成交持仓比：`价格 / 成交持仓比`
- 持仓：`价格 / 持仓`
- 现货价、电价、CIF/FOB、自提价、均价、价格指数：`价格 / 现货价格`

示例：

- `SMM: 新疆金属硅主产地电价: 最低价`：`价格 / 现货价格`
- `SMM: P型多晶硅价格指数 - 平均价`：`价格 / 现货价格`
- `GFEX: 工业硅: 主力合约: 收盘价`：`价格 / 期货价格`

### 4. 平衡表分项

平衡表里的每个指标按自身含义分类，不因为整张表叫“平衡”而全部归 `平衡/平衡`。

- `平衡值`：`平衡 / 平衡`
- `产量`：`供给 / 产量`
- `供应量`：`供给 / 数量`
- `进口量`：`进出口 / 进口`
- `出口量`：`进出口 / 出口`
- `净出口`：`进出口 / 净出口`
- `消费量/需求量`：`需求 / 需求`

### 5. 供需进出口类

- `产量/发电量/排产`：`供给 / 产量`
- `产能`：`供给 / 产能`
- `开工率/开工`：`供给 / 开工率`
- `装机量/装机容量/用电量/消纳/消费/需求/销量/出货量`：`需求 / 需求` 或 `需求 / 销量`
- `进口量`：`进出口 / 进口`
- `出口量`：`进出口 / 出口`
- `净出口`：`进出口 / 净出口`

### 7. 参数与宏观类

- PMI 及其子指数：`其他 / 宏观`
- 转换效率、市场占比、市场份额、功率、电压、厚度、人均产出、折算标准等：`其他 / 参数`

## 单位辅助判断

- `元/吨`、`美元/吨`、`元/千克`、`元/片`、`元/瓦`、`元/平方米`、`元/kWh` 等通常是价格或成本类单位。
- `万吨`、`吨`、`GW`、`万千瓦`、`亿千瓦时`、`手` 等通常是数量、库存、供需、进出口类单位。
- `%`、`天`、`kW/台`、`mg/片`、`kWh/kg-si` 等通常用于开工率、库存天数、参数或成本参数。

## 禁止出现的不一致

- 平衡表内的 `进口量/出口量/产量/消费量` 不得全部写成 `平衡/平衡`。
- 价格指数不得写成 `其他/指数`。
- 电价不得写成 `供给/数量`。
- 进口库存不得写成 `进出口/进口`。
- PMI 子表中的库存指数不得写成 `其他/宏观`。

## AI 辅助判断

确定性复核完成后再执行 `scripts/ai_assisted_curation.py`，仅对未识别/多候选/单位冲突指标调用 DeepSeek，不替代硅产业确定性规则。

触发条件：

- 大类或子类为“其他”
- 指标标签含“未识别、未指定”
- 单位与大类存在冲突

执行流程：

1. 保留确定性规则结果。
2. 将触发项按 20-50 条/批发送给 DeepSeek。
3. 模型返回严格 JSON，字段与“大类/子类/数据性质/指标标签”一致。
4. 对模型结果执行单位一致性检查。
5. 结果写入本地 SQLite 缓存，重复运行不重复消耗 token。

单位一致性检查示例：

- `元/吨`、`美元/吨`、`元/kWh` 应对应“价格”或“成本利润”
- `吨`、`万吨`、`GW`、`手` 等数量单位不应归为“价格”
- `%`、`天` 等比率/天数单位不应归为普通价格或数量

命令示例：

```bash
python scripts/ai_assisted_curation.py --input output/硅产业链数据_processed.xlsx --industry silicon --dry-run
python scripts/ai_assisted_curation.py --input output/硅产业链数据_processed.xlsx --industry silicon
```
