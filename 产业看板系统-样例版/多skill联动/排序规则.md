# 看板排序规则

本文档描述当前看板图表排序、归组和行排布的职责边界与执行规则。

## 1. 唯一业务排序真源

```text
Skill4 最终输出 Excel 的指标目录行顺序
  -> server.py 转成 catalog_order
  -> Dashboard 按 catalog_order 结构化展示
  -> Row Packing
```

职责边界：

- Skill4：唯一业务排序真源。大类、子类、频率、产业链节点、天然/人造路线、实际/预测、中国/海外、规格/用途/地区的业务顺序都由 Skill4 排好。
- `server.py`：只负责把 Excel Sheet1 行顺序转成 `catalog_order`，并同时向前端输出 `catalogOrder`。
- Dashboard：只按 `catalog_order` 读取，做大类/子类/频率结构分区、Display Block 归组和最多 5 张图的行排布。

Dashboard 禁止重新决定以下顺序：

- 大类谁先谁后
- 子类谁先谁后
- 日/周/月/季/年谁先谁后
- 产业链上下游谁先谁后
- 天然/人造路线谁先
- 实际/预测谁先
- 中国/海外谁先
- 规格、用途、地区的业务优先级

## 2. 结构分区

Dashboard 保留板块、子类标题和导航，但只作为结构分区，不再作为第二套业务排序表。

- **一级 = 板块**（按数据源自动识别产业链顺序表，数据中没有的板块跳过，板块顺序 = 该板块所有 chart 的最小 `catalog_order` 兜底）：
  - 锂电：`锂矿 → 碳酸锂 → 氢氧化锂 → 其他锂盐 → 磷酸铁锂 → 磷化工链 → 三元正极 → 钴酸锂 → 锰酸锂 → 负极材料 → 隔膜 → 电解液产业链 → 辅材 → 电池电芯 → 储能 → 新能源汽车`（锂盐拆分板块按 碳酸锂 < 氢氧化锂 < 其他锂盐，磷化工链归入磷酸铁锂）
  - 锡：`锡矿 → 锡锭 → 锡材 → 铅蓄电池 → 镀锡板 → 锡下游 → 锡期货 → 锡其他`（采选→冶炼→加工→下游应用→衍生品→杂项殿后）
  - 硅：`硅石石英砂 → 硅基原料 → 工业硅 → 有机硅 → 多晶硅 → 硅片 → 电池片 → 组件 → 光伏辅材 → 铝合金 → 下游需求`（原料→冶炼→提纯→加工→终端）
  - 识别逻辑：`buildIndustryGroups` 按 charts 的板块集合匹配 锡/硅/锂电 顺序表（`detectSectorOrder`）
- **二级 = 子类**（跨大类收集、同名合并），板块内子类固定顺序（价格类：`现货价格 → 贸易金额 → 期货价格 → 现货价差 → 价差 → 基差 → 月差 → 指数`，与数据侧 `sort_catalog.SUB_ORDER` 一致），其他子类按最小 `catalog_order`
- **三级 = 频率**（日度 → 周度 → 月度 → 季度 → 年度），频率内按产品/指标类别（`productRankOf` + 产品基础名连续 + 形态层级 + 产品标签连续 + 合约系列 + min `catalog_order`）：产品基础名相同者按形态层级 电芯(0) < 电池(1) < Pack(2) 排列，使 Pack 紧跟对应电芯/电池系列（如"三元Pack"紧跟"三元电芯"、"磷酸铁锂Pack"紧跟"磷酸铁锂电池"）
- 大类（价格/供给/需求/成本利润/库存）不再单独成层，其顺序规则（价格 → 成本利润 → 库存 → 供给 → 需求）失效，由板块顺序取代
- 板块别名：数据侧"锂盐"被拆为 碳酸锂/氢氧化锂/其他锂盐；"磷化工链"（磷矿/磷酸/磷酸铁等）归入"磷酸铁锂"板块一并筛选排序（展示侧合并：前端 `buildIndustryGroups` 将 sector 字段归一化为"磷酸铁锂"，总览与磷酸铁锂板块页均不显示"磷化工链"；后端 `_filter_by_sector_aliases` 已按别名扩展过滤）；锡板块"锡下游"Tab 经后端 `TIN_SECTOR_ALIASES` 一并返回 铅蓄电池/镀锡板 数据（数据侧无"锡下游"板块，铅蓄电池/镀锡板即锡下游应用）
- Display Block 归组 key 含板块维度：同一标题在不同板块的重复数据（如"储能型电芯"的储能版/电池电芯版）必须分开

```text
groupOrder = min(catalog_order)
```

同一板块、子类、频率内部保持 Excel `catalog_order` 顺序。

产业板块 Tab 顺序仍由页面 `TABS` 固定，例如锂电、锡、硅的板块导航顺序；Tab 是页面导航结构，不改变 Excel 指标顺序。

## 3. Display Block

普通图表的最小 Display Block Key：

```text
大类 + 子类 + 频率 + 归一化指标名称
```

例如：

```text
价格 + 现货价格 + 日度 + 磷矿石
```

同一个 Display Block 内的图：

- 必须保持 `catalog_order`
- 必须作为一个完整视觉组
- 不允许被其他指标名称插入
- 不允许因地区、来源、实际/预测等原因再次拆开

不同 Display Block 之间：

```text
block_order = min(catalog_order)
```

禁止按中文名称、归一化名称、产业节点 rank、地区或置信度重新排序。

### 业务同行组 Display Group

`display_group` 只用于把同一业务同行指标固定为同一个 Display Block，不参与
纵向排序。纵向顺序始终由 Skill4 最终 Excel 的 `catalog_order` 决定。

当前唯一业务同行组：

```text
display_group = 港口库存
```

- `display_group` 必须由 Skill4 / 后端结构化数据写入 `指标标签`，Dashboard
  不得通过标题关键词自行识别“港口库存”等业务知识。
- 同一 `大类 + 子类 + 频率 + product_family` 下，`display_group=港口库存`
  的指标统一形成一个连续 Business Display Group。
- 港口库存组内保持 `catalog_order`；如能稳定识别“总计”，则总计优先，其余
  具体港口不额外建立复杂 rank，继续保持既有目录顺序。
- 港口库存组与普通库存之间的先后顺序由 Skill4 最终 Excel `catalog_order`
  体现，Dashboard 不搬动港口库存。
- 可售库存、贸易商库存、外采库存、厂内库存、在途库存、矿山样本库存、
  锂盐厂样本库存等其他库存不设置 `display_group`，继续作为普通
  Display Block / singleton 按现有 `catalog_order` 展示。

港口库存组遵守同一 Display Block 的 Row Packing 规则：

```text
6  -> 3 + 3
7  -> 4 + 3
8  -> 4 + 4
11 -> 4 + 4 + 3
```

## 4. 指标名称归一化

归一化只用于判断哪些 charts 属于同一个 Display Block，不决定 block 先后，也不修改原始标题。

当前会删除：

- 数据来源前缀：`SMM:`、`Mysteel:`、`百川:`、`Wind:`、`iFind:`
- 交易所前缀：`SHFE:`、`GFEX:`、`DCE:`、`CZCE:`、`INE:`
- 通用变量词：价格、成交量、成交额、持仓量、库存、产量、产能、进口、出口、合计、总额、总量、金额、成本、价差、基差、月差、同比、环比等
- 通用规格/来源词：国产、含税、不含税、出厂、到厂、到港、均价、平均价、长单、散单、现货、期货、型号、规格、粒度、纯度、含量等
- 通用维度词：`分州级`、`分省份`、`分国别`、`分车型级别`、`分燃料类型`、`分环节`、`分仓库`、`分电池类型` 等及其后的维度值
- 括号内容、半角/全角括号、`Fe/P` 类参数、百分比区间（**含"电解液"的指标保留括号**——"电解液（三元动力用）"与"电解液（磷酸铁锂用）"是不同规格指标，不应归并为同一 Display Block，否则多种电解液报价合并为大 block 独占行、相邻六氟磷酸锂无法并入同行）
- 频率后缀：日度、周度、月度、季度、年度
- 中文月份转数字，如“一月”转 `01`

上下文特殊规则：

- 指标名含“人造石墨”或“石墨”时，删除“储能、动力、消费”。
- 指标名含“电芯出货”时，删除“三元、磷酸铁锂、总计、合计”。
- 指标名含“分电池类型”或“库存分电池类型”时，删除具体电池类型词。
- 指标名含“电解液”时，`productRankOf` 直接返回末位（不参与 碳酸锂/磷酸铁锂 等产品 rank）——"电解液（磷酸铁锂用）"中的磷酸铁锂是用途词，不是产品。

归一化结果为空时回退使用 `chart.id`，避免不同图被错误合并。

## 5. Row Packing

一行最多 5 张图。

### 同一 Display Block

- `N <= 5`：全部放同一行。
- `N > 5`：最小差值均分。

```text
6  -> 3 + 3
7  -> 4 + 3
8  -> 4 + 4
9  -> 5 + 4
10 -> 5 + 5
11 -> 4 + 4 + 3
12 -> 4 + 4 + 4
13 -> 5 + 4 + 4
14 -> 5 + 5 + 4
15 -> 5 + 5 + 5
```

禁止 `6 -> 5 + 1`、`7 -> 5 + 2`、`11 -> 5 + 5 + 1`。

### 多图 Display Block

- `N >= 3` 的 Display Block 独占自己的行或多行（`N > 5` 时最小差值均分）。
- `N = 2` 的 Display Block 不独占行，可与相邻的 2 张块（2+2=4）、3 张块（2+3 或 3+2=5）或 singleton（如 2+1+2=5）合并到同一行；连续三个 2 张块按 `4+2` 拆行。
- 3 张块仅可与相邻的一个 2 张块组合为一行（3+2=5），不与 singleton 或其他块混行。
- 组合行与 singleton 合并行均保持 大类/子类/频率/板块 硬边界（不同板块的图不合并到同一行，如"磷酸锰铁锂"（磷酸铁锂板块）不与"三元前驱体"（三元正极板块）同行），且不拆分 Display Block。

### 连续 singleton Display Block

只有同时满足以下条件的连续 singleton 才能合并到同一行：

- 同一大类
- 同一子类
- 同一频率
- 同一板块
- `catalog_order` 连续

频率、大类、子类、板块是 Row Packing 的硬边界；产品/规格维度不阻止合并
（同板块同子类同频率的 singleton 可跨产品合并为一行，如碳酸锂板块 成本-日度
的 碳酸锂/磷酸铁锂/锂云母精矿 等原料路线成本单图按 5+1 均分）。

连续 singleton 超过 5 张时，同样使用最小差值均分。

## 6. 特殊 Composite Display Block

### 进出口

同一产品的进口、出口、净出口可形成 Composite Display Block：

```text
进口 -> 出口 -> 净出口
```

组内顺序固定，组间顺序仍由 `min(catalog_order)` 决定。

数据侧（`sort_catalog`）排序层级（硬顺序）：

```text
板块 → 大类(MAJOR_ORDER) → 复合组 → 复合 role → 大类内子类(SUB_ORDER)
     → 频率 → 业务块 → 产品族 → 地区 → 当期/预测 → 来源 → 规格 → 名称
```

- 大类层是板块内的硬顺序：价格 → 成本利润 → 库存 → 供给 → 需求 → 进出口 → 平衡；
  大类层必须保留，跨大类直接比较各 `SUB_ORDER` 的独立索引没有业务依据
  （如"库存"子类索引 0 会排在"现货价格"索引 1 之前）。
- 同 rank 板块必须有次级键（`SECTOR_SUB_RANK`）：板块一级排序用
  `(SECTOR_RANK, SECTOR_SUB_RANK)`，若同 rank 板块缺少次级键，它们的段会按
  大类交错排列而非板块分组连续。已覆盖：碳酸锂 < 氢氧化锂 < 其他锂盐
  （rank 1）、磷酸铁锂 < 磷化工链（rank 2）。新增同 rank 板块时必须同步
  补充次级键。
- 复合组 role 排序仅对 `MATCHED`（配对成功）组生效；未配对（`INCOMPLETE`）的
  进出口/成交持仓行 role 与普通行一致（9999），不会以 role=0 插队到板块最前
  （段排序取段内最小排序键，未配对行不再把所在段拉到最前）。

前端实现：

- 进出口图表的归组 key 统一由 `industryGroups.tradeGroupKey` 生成：同一产品 + 地区/国别维度 + 频率 + 量/额 的 进口、出口、净出口 返回相同 key。
- 进出口不使用数据侧 composite 标签：净出口的 `composite_key` 与进口/出口不一致且 status 通常为 `INCOMPLETE`，依赖标签会把净出口单独拆行。
- 行排布（`chartGrouping.displayBlockKey`）与导航分组（`buildTradeSubGroups`）共用同一 key，保证两类分组一致。
- 频率优先从标题提取（标题标注"月度"等统计口径；即使 `freq` 字段为 daily 更新频率，也按标题口径同行），标题无频率词时回退 `chart.freq`；标题尾部 `-月`/`-季` 缩写频率同样识别。
- 频率词（月度/周度/季度/年度）无论出现在标题哪个位置都删除，由提取出的频率承担区分。
- 标题中"海关后紧跟的中国"（如"中国海关: 中国金属锂进口量"）视为冗余删除，以便与"中国海关 金属锂净出口"对齐。
- 复合组行内固定业务顺序（`groupChartRows` 组内排序）：进出口 `进口 -> 出口 -> 净出口`；成交持仓 `成交量 -> 成交 -> 持仓 -> 持仓量 -> 成交持仓比`。其他组保持 `catalog_order`。
- 组内"总计/合计"汇总图优先排最前（如"产能分国别: 总计"应在各国之前），其余仍按 `catalog_order`。
- 实际值与其预测值配对相邻：去掉标题中"预测值/预测"（含前置连字符）后相同的图视为一对，实际值在前、预测值紧跟其后（如 产量、产量-预测值、进口量、进口量-预测值）；配对组之间按组内最小 `catalog_order`。

### 成交持仓

成交量、成交、持仓、持仓量、成交持仓比可形成 Composite Display Block：

```text
成交量 -> 成交 -> 持仓 -> 持仓量 -> 成交持仓比
```

组内顺序固定，组间顺序仍由 `min(catalog_order)` 决定。

### 合约系列

同一产品（去掉合约标识后同名）内的合约系列排序：**主力合约 -> 当月合约 -> 一月/二月/…/十二月**（含 `01/05` 数字合约、`连X` 合约按数字），非合约标题保持 `catalog_order`。用于：

- 行排布组间/组内排序（`chartGrouping.groupChartRows`，`contractBaseName` 判定同系列、`contractRankOfTitle` 排名）
- 导航分组排序（`industryGroups.buildVolumeOiSubGroups` 与 `sortSubsBySector`）

示例：碳酸锂期货系列当前数据目录中主力合约 `catalog_order` 靠后，但业务上必须排在 一月/五月/九月 等合约之前。

## 7. 大类与产品顺序

- 大类显式顺序（总览与板块页统一）：`价格 -> 成本利润 -> 库存 -> 供给 -> 需求`，其他大类排最后（`industryGroups.majorRankOf`）；同类内保持 `catalog_order`
- 产品级排序（同板块内，`productRankOf`）：碳酸锂在氢氧化锂前（0 < 1）；磷酸铁 -> 磷酸铁锂 -> 磷酸锰铁锂（2 < 3 < 4）；判定按标题关键词，先匹配更长/更具体的产品名（磷酸锰铁锂/磷酸铁锂 含"磷酸铁"子串需先排除）；三元材料家族内按系别 5系 < NCA < 6系 < 8系 < 9系（`compareProductKeys` 同"三元材料"标签时生效，使 NCA 三元材料与 5系 相邻并入"三元前驱体-日度 ｜ 三元材料-日度"行）
- 频率维度由数据目录保证（Skill4 规则：先同频率 日度 -> 周度 -> 月度 -> 季度 -> 年度，频率内按产品上下游节点）；块间排序键（`groupChartRows.groupList`）不再干预频率：板块 -> 产品 rank -> 产品基础名（去电芯/电池/Pack 后缀）首次顺序 -> 形态层级（电芯 < 电池 < Pack）-> 产品标签首次顺序 -> 合约 rank -> min(catalogOrder)
- 专属行排布（非通用规则，针对当前数据，后续可调整）：三元正极板块 现货价格-日度 段，三元前驱体 6 个指标（5/6/8 系 × 单晶/多晶）按 **3+3** 两行、三元材料 8 个指标（5/6/8 系 × 单晶/多晶 + 9系 + NCA）按 **4+4** 两行，前驱体组与材料组互不混行；前提是归一化对"三元前驱体/三元材料"保留括号（单晶/多晶 拆为独立指标），实现于 `groupChartRows` 开头的专属分支
- 二次筛选规则：情绪因子相关指标（如"磷酸铁出货/成交/购货情绪因子"）不保留

## 8. 个股排序

个股池（`data/stock_targets/个股标的_*.xlsx`）的总览与各板块 Tab 统一排序：

- 一级：按产业链上下游环节（`上游 -> 中游 -> 下游`，无环节排最后），环节取"所属环节"列前缀匹配（多环节取最小）
- 二级：环节内按板块（细分板块）产业链顺序 `锂矿 -> 锂盐 -> 三元正极 -> 磷酸铁锂正极 -> 负极 -> 隔膜 -> 电解液 -> 铜箔铝箔 -> 电池&电芯 -> 储能&集成 -> 新能源车`，多板块取最小
- 三级：同板块内按市值降序，市值优先取实时行情 `mcap_yi`（腾讯），缺失回退 Excel"总市值(亿)"列

执行位置：

- 后端 `server.py _load_stock_targets()`：读"总市值(亿)"列与"细分板块"写入 `stock_meta.market_cap` / `stock_meta.subs`；`groups`（总览=全板块去重合并及各 Tab）按数据源选用 `STOCK_SUB_ORDERS`（lithium/tin/silicon 各表）统一按 (环节 rank, 板块 rank, 市值降序, 代码) 排序，决定 watchlist / market-data / financials / reports 的请求与截取顺序
- 前端 `Battery.tsx`：`sortBySegmentAndCap`（含 `STOCK_SUB_ORDER` 板块顺序表，与后端一致）应用于总览/板块切换、增删股票后的 `stockCodes`；核心标的池渲染时再用实时市值重排（`mcap_yi > 0` 用实时，否则回退 Excel 市值）

## 9. Skill4 数据目录重排执行规则

Skill4 的 `sort_catalog.py` 按本文档重排 Excel 的 `指标目录` sheet，不修改指标分类字段，也不改动其他数据 sheet：

- 不修改目录单元格内容；sheet 段按指标规则顺序排列，sheet 名称随所在数据段整体移动，段内数据行再按规则排序。
- 每个 sheet 段内选中行在前、未选中行在后；统计行和伪指标行放到整个目录最下方。
- 同一大类/子类/频率/中国外国/同类指标分组下，按板块内部产业链节点顺序收尾排序；节点规则见 `skills/dashboard-data-sorter/config/sector_node_rules.json`。
- 地区顺序：无地区（通用指标，如 `磷酸 - 平均价`）排前，其次中国/中国省份
  （如 `磷酸（云南）`），全球/海外/外国最后；括号内 `CIF中国/中国现货`
  不作为中国依据，括号外指向外国时按外国处理。
- 大类为“其他”且名称含“低端/中端/高端”的指标，以及负极材料“人造石墨平均价”类指标，统一按 低端 -> 中端 -> 高端 排序。
- 排序后保留并重建目录跳转超链接。
- 重写目录前清除旧合并单元格区域，避免旧表头合并区域盖住移动后的指标名、单位、板块等单元格。
- Skill4 重排的是目录行顺序；Dashboard 展示层按本文档第 3、5、6 节形成 Display Block 和 Row Packing。
