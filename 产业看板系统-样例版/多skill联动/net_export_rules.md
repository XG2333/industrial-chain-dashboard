# 净出口计算公共规则

本规则适用于锂电、硅、锡以及后续新增产业链，不按产业区分。

## 文件位置

- 公共执行脚本：`scripts/calculate_net_exports.py`
- 核心计算逻辑：`financial_variable_curation/rules/net_export_calculator.py`
- 兼容旧脚本：`scripts/calculate_silicon_net_exports.py`

## 作用

在目录完成分类和产业专属筛选后，自动检查“进口”和“出口”月度总量是否成对出现：

- 只有进口没有出口的指标：筛除，不生成净出口。
- 只有出口没有进口的指标：筛除，不生成净出口。
- 已有净出口但没有对应进口和出口配对的指标：同样筛除。
- 进口、出口成对存在时，如果缺少对应的“净出口”指标，则：

1. 按同一指标口径，将出口量减去进口量。
2. 按日期对齐，任一日期缺少进口或出口数据时跳过该日。
3. 在 `净出口计算` sheet 写入计算得到的时间序列。
4. 在目录末尾追加一条指标：
   - 大类：进出口
   - 子类：净出口
   - 数据性质：流量
   - 是否选中：是
   - 状态说明：确定性净出口计算

## 触发条件

净出口计算只处理以下目录行：

- 大类为“进出口”
- 子类为“进口”或“出口”
- 标题包含“总计/合计/总量”
- 标题不含“进口额/出口额/净出口额/金额/均价/平均价”等金额或价格口径
- 标题以“月度”结尾时按月度处理，优先于目录 Sheet 中可能写错的频率
- 分国别、分省份 Sheet 中的“总计/合计/总量”行同样参与配对
- 同一指标口径下同时存在进口和出口
- 该口径尚未存在“净出口”指标

若同一指标口径只有进口或只有出口，则该指标不保留，也不应存在净出口行。

## 口径匹配规则

核心函数 `metric_key` 会移除以下干扰词后再匹配，且配对可跨 Sheet：

- `进口量`、`出口量`、`净出口`
- `总计`、`合计`、`总量`
- 频率后缀：`月度`、`周度`、`季度`、`年度`、`日度`

因此 `碳酸锂进口量: 总计: 月度` 与 `碳酸锂出口量: 总计: 月度` 会被视为同一口径，并生成：

```text
碳酸锂净出口: 月度
```

## 边界处理

1. 目录 Sheet 频率写错时，以标题中的 `月度/日度/周度/季度/年度` 为准。
2. 进口和出口可位于不同 Sheet，计算时分别读取进口 Sheet 与出口 Sheet 的列。
3. 均价、平均价、价格类进出口不参与计算，也不保留。
4. 进口额、出口额、净出口额、金额等金额类进出口不参与计算，也不保留。
4. 同一口径存在多条进口或出口时，优先保留子类明确的 `进口/出口` 行。
5. 已存在多条净出口时只保留一条，其余不选中。
6. `中国金属锂` 与 `金属锂`、`日本海关` 与错误拆词后的写法，按统一口径归一后配对。

## 计算方式

```text
净出口 = 出口量 - 进口量
```

按日期对齐，任一日期缺少进口或出口数据时跳过该日。

## Workflow 接入

锂电、硅、锡的 workflow 都应在产业专属筛选前执行净出口计算：

- `configs/workflow_lithium.yaml`
- `configs/workflow_silicon.yaml`
- `configs/workflow.yaml`

统一命令：

```yaml
- id: calculate_net_exports
  name: 净出口计算
  runner: command
  enabled: true
  in_place: true
  params:
    timeout_ms: 900000
    command:
      - 'C:/Users/11/Documents/Selecting skill/.venv/Scripts/python.exe'

      - '{input}'
```
## 数量平衡硬校验

进出口总量标题可能写作 `进口量/出口量`，也可能直接写作
`进口/出口/净出口`。最终产业筛选必须处理全部目录行，不能只依赖 Skill2
预先选中的结果；只要同一口径存在月度进口和出口，就应保留进口、出口以及
对应净出口，并筛除其余重复或聚合行。

每次 `apply_industry_selection.py` 保存前必须校验：`进出口` 大类下
`进口`、`出口`、`净出口` 三个子类的选中数量必须相等，否则流程直接失败。
