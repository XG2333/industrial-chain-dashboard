# 硅产业链分类复核规则 (reclassify_silicon.py)

## 用途

Skill2 完成初步分类后执行，修正大类/子类错误、剔除伪指标、重排进出口顺序。

## 判定方式

当前脚本不再按固定优先级顺序匹配。它调用
`scripts/classification_candidates.py` 的硅产业候选分组：

1. 指标名称命中多个大类时，全部收集。
2. 指标名称未命中大类时，才回退到 Sheet 名称。
3. 同一大类下命中多个子类时，全部收集。
4. 唯一候选直接采用；多个候选写入 `候选大类`、`候选子类` 和
   `候选分类组合`，等待 AI 消歧。

保留的规则行为：

- 伪指标行继续剔除。
- 进出口类指标继续按 净出口 → 进口 → 出口 排序。

## 伪指标剔除

名称 = `指标名称` 且单位 = `单位` 的行从目录中删除。

## 进出口排序

进出口类指标(大类=进出口)在逐个 Sheet 段内按 净出口 → 进口 → 出口 排列，同类型内部按名称排序。
