# 硅产业链指标标签规则 (apply_indicator_tags.py)

## 用途

在现有树状分类（板块 → 大类 → 子类）之外，为每条指标生成一组独立、扁平的
“指标标签”。标签写入目录 Sheet 的新增列 `指标标签`，不增加新的树状层级，
也不替代 `大类/子类` 分类。

## 输出格式

`指标标签` 列保存 JSON 对象，例如：

```json
{
  "产品": "工业硅",
  "研究主题": "价格",
  "指标类型": "现货价格",
  "规格": "553#",
  "工艺属性": "通氧",
  "地域": "新疆",
  "统计口径": "平均价",
  "状态": "实际",
  "频率": "日度"
}
```

未识别到具体值的维度统一记为 `未识别`，便于后续检查补规则。

## 维度

| 维度 | 说明 | 示例 |
|---|---|---|
| 产品 | 指标对应的硅产业链产品 | 工业硅、多晶硅、硅片、电池片、组件 |
| 研究主题 | 该指标研究的主题 | 价格、库存、供给、需求、进出口、成本利润、平衡、其他 |
| 指标类型 | 指标的具体计量类型 | 现货价格、期货价格、库存、产量、净出口 |
| 规格 | 产品规格或型号 | 553#、421#、182mm、N型、M10 |
| 工艺属性 | 产品工艺或形态 | 通氧、不通氧、致密料、再生、单晶、多晶 |
| 地域 | 地区、港口或国家 | 新疆、华东、黄埔港、美国、中国 |
| 统计口径 | 指标的统计方式 | 平均价、收盘价、分仓库、总计、净出口 |
| 状态 | 实际值或预测值 | 实际、预测、计划、估算 |
| 频率 | 数据频率 | 日度、周度、月度、季度、年度 |

## 产品抽取规则

优先从指标名称抽取，未命中时再使用所在 Sheet 名称。规则按优先级排列：

1. 光伏辅材：光伏玻璃、光伏胶膜、EVA胶膜、光伏背板、逆变器、焊带、光伏边框、光伏支架、光伏网板、光伏硅胶
2. 硅片：硅片、182mm、210mm、166mm、M10、M12、G12
3. 电池片：电池片、PERC、TOPCon、HJT、BC电池
4. 组件：组件、T型、双玻、单玻
5. 多晶硅：多晶硅、硅料、致密料、菜花料、复投料、颗粒硅
6. 工业硅：工业硅、金属硅、553、441、421、3303、2202、2205、1101、521、551、411、97硅、99硅、通氧、不通氧
7. 有机硅：有机硅、DMC、硅油、生胶、107胶、110胶、白炭黑
8. 其他原料：三氯氢硅、硅粉、石英砂、硅石、铝合金
9. 需求侧：装机、发电、用电、消纳、消费、需求

## 研究主题抽取规则

按以下关键词判定，名称优先，其次使用现有 `大类`：

| 研究主题 | 关键词 |
|---|---|
| 价格 | 价格、电价、均价、平均价、收盘价、结算价、基差、月差、价差、持仓、成交量 |
| 成本利润 | 成本、利润、LCOE、折旧、人工、电耗、水耗、能耗、耗量、消耗、浆料、银浆、盈亏 |
| 库存 | 库存、仓单 |
| 供给 | 产量、产能、开工率、供应量、排产、发电量 |
| 需求 | 需求、消费、装机、用电、消纳、出货、销量 |
| 进出口 | 进口、出口、净出口 |
| 平衡 | 平衡 |
| 其他 | PMI、指数、效率、占比、功率、电压、厚度 |

实际判定优先级如下，避免 `进口/出口`、`消费`、`平衡表` 等词互相干扰：

1. Sheet 或名称含 `PMI`：`其他`
2. 名称含 `平衡值`：`平衡`
3. 名称含 `成本指数`、`成本模型`、`成本(`、`初始投资`、`成本/利润` 等：`成本利润`
4. 名称含价格特征词：`价格`
5. 名称含 `进口/出口/净出口`：`进出口`
6. 其余按 库存/供给/需求 判定

价格特征词包括：`价格`、`电价`、`均价`、`平均价`、`收盘价`、`结算价`、
`低价`、`高价`、`CIF`、`FOB`、`自提价`、`港口价`、`出厂价`、`到港价`、`含税`、`不含税`。

例如 `SMM: 进口ADC12宁波CIF低价` 是进口铝锭价格，标签应为 `价格/现货价格`，
不能因为名称含“进口”就归入 `进出口`。

## 指标类型抽取规则

从名称中按优先级识别；无法识别时使用现有 `子类`，仍无法识别时使用 `大类`。

| 指标类型 | 关键词 |
|---|---|
| 成交持仓比 | 成交持仓比 |
| 成交量 | 成交量 |
| 持仓 | 持仓 |
| 月差 | 月差 |
| 基差 | 基差、期现、期现价差、升贴水 |
| 现货价差 | 现货价差、价差 |
| 期货价格 | 期货价格、主力合约、合约、收盘价、结算价 |
| 现货价格 | 平均价、均价、现货价格、现货价、最低价、最高价、电价、出厂价、到港价、港口价、CIF、FOB、自提价 |

说明：价格大类的子类统一为“现货价差”后，基差作为指标类型保留，用于区分价差下的基差细类。
| 成本 | 成本、LCOE、折旧、人工、投资、电耗、水耗、能耗、耗量、浆料、银浆 |
| 利润 | 利润、盈亏 |
| 库存指数 | 库存指数 |
| 库存天数 | 库存天数 |
| 仓单 | 仓单 |
| 库存 | 库存 |
| 产量 | 产量、发电量、排产 |
| 产能 | 产能 |
| 开工率 | 开工率、开工 |
| 净出口 | 净出口 |
| 出口 | 出口 |
| 进口 | 进口 |
| 销量 | 销量、出货 |
| 需求 | 需求、消费、装机、用电、消纳 |
| 平衡 | 平衡 |
| 宏观 | PMI、宏观 |
| 参数 | 效率、占比、功率、电压、厚度、参数 |

实际判定优先级如下：

1. PMI 子指数：`宏观`
2. `平衡值`：`平衡`
3. `供应量`：`数量`
4. `成本指数`：`成本`
5. 期货价格、月差、基差、持仓、成交量、现货价格等具体类型
6. 净出口、出口、进口
7. 需求、库存、供给等其余类型

例如：

- `全球多晶硅供需平衡表: 供应量` 应为 `供给/数量`，不是 `平衡`。
- `光伏级EVA成本(油制): EVA粒子价格` 研究主题为 `成本利润`，指标类型为 `现货价格`。
- `Topcon183组件成本指数 - 平均价` 应为 `成本利润/成本`。
- `原生铝合金新出口订单指数` 是 PMI 子指数，应为 `其他/宏观`，不是实际出口。

## 已知边界案例

- `SMM: 有机硅DMC均价` 是实际现货价格，标签固定为 `价格/现货价格`；
  即使所在 Sheet 属于成本利润，也不能把该指标标签改成 `成本`。
  此时应复核现有 `大类/子类` 是否为 `成本利润/成本`，而不是改指标标签。
- 成本模型中的“价格”同时具备成本和价格属性：`研究主题` 取 `成本利润`，
  `指标类型` 保留 `现货价格`；只有明确的 `成本指数` 才把 `指标类型` 标为 `成本`。

## 规格、工艺、地域、统计口径

- 规格：识别 `553#`、`421#`、`97硅`、`N型/P型/T型`、`182mm`、`M10`、`G12`、`72片` 等。
- 工艺属性：识别 通氧、不通氧、化学级、冶金级、高纯、致密料、菜花料、复投料、颗粒硅、粉料、块状、粒状、原生、再生、免洗、湿法、干法、流化床、单晶、多晶、单玻、双玻。
- 地域：识别国内省份、区域、港口以及主要国家/地区。
- 统计口径：优先识别 加权平均价、平均价、均价、最低价、最高价、收盘价、结算价、出厂价、到港价、港口价、含税、不含税、分仓库、分地区、分国别、总计、合计、总量、进口量、出口量、净出口、开工率、PMI、指数 等。

## 状态与频率

- 状态：名称或 Sheet 含 `预测/计划/目标/预算/估算` 时取对应状态，否则为 `实际`。
- 频率：优先取目录 `Freq` 列，其次从指标名称后缀识别 `日度/周度/月度/季度/年度`。

## 与现有分类的关系

`板块/大类/子类` 继续保留，用于原有筛选和检查；`指标标签` 是新增的独立标签维度，
用于表达一个指标同时具有产品、主题、规格、工艺、地域、统计口径等多个属性，不再扩展树状层级。
