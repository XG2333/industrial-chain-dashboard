# 锡产业链大类、子类与数据性质规则

规则实现位置：

- 确定性候选：`scripts/classification_candidates.py`
- 锡标签与数据性质：`scripts/tin_rules.py`

使用位置：`scripts/apply_tin_curation.py` 的目录后处理。

## 大类判定

与锂电共用同一套候选机制。先收集指标名称命中的全部大类，Sheet 名称仅作
回退；唯一命中直接采用，多个命中写入 `候选大类`，等待 AI 消歧：

1. `平衡`：含“平衡”
2. `成本利润`：含“成本、利润、毛利率、盈亏”
3. `进出口`：含“进出口、进口、出口、出港、到港、贸易流向、净出口、发货量、航运”
4. `库存`：含“库存、仓单、库容、库销比、库存天数、库存周期”
5. `供给`：含“产量、产能、开工、排产、自给率、储量、市占率、供应、冶炼、CR5、集中度、出货情绪、加工费”
6. `需求`：含“需求、消费、销量、出货量、装机、招标、中标、上险、保有量、带电量、渗透率、装车、充电桩、换电站、批发、零售、消耗量、配储、要求、建成规模、工商业储能、购货情绪、成交情绪”
7. `价格`：含“价格、平均价、均价、售价、基差、价差、月差、收盘价、结算价、指数、现货、期货、CIF、FOB、升贴水、溢价、成交量、成交持仓比、持仓”
8. `其他`：未命中以上关键词

通用实现和消歧规则见
[classification_candidates_rules.md](classification_candidates_rules.md)。

- 多个候选写入 `候选子类`，等待 AI 消歧。

## 数据性质

- `差值`：子类为价差（含基差）、月差
- `比率`：含“开工率、自给率、渗透率、库销比、市占率、利用率、占比、比例”
- `存量`：大类为库存
- `流量`：大类为供给、需求、进出口
- 默认：`水平值`

## AI 辅助判断

确定性规则完成后再执行 `scripts/ai_assisted_curation.py`，仅对未识别/多候选/单位冲突指标调用 DeepSeek，不替代锡产业确定性规则。

触发条件：

- 大类或子类为“其他”
- 指标标签含“未识别、未指定”
- 单位与大类存在冲突

执行流程：

1. 保留确定性规则结果。
2. 将触发项按 20-50 条/批发送给 DeepSeek。
3. 模型返回严格 JSON，字段与“大类/子类/数据性质/指标标签”一致。
4. 当指标存在候选字段时，模型必须从候选列表中选择大类/子类。
5. 对模型结果执行单位一致性检查。
6. 结果写入本地 SQLite 缓存，重复运行不重复消耗 token。

单位一致性检查示例：

- `元/吨`、`美元/吨`、`元/kWh` 应对应“价格”或“成本利润”
- `吨`、`万吨`、`GW`、`手` 等数量单位不应归为“价格”
- `%`、`天` 等比率/天数单位不应归为普通价格或数量

命令示例：

```bash
python scripts/ai_assisted_curation.py --input output/锡产业链数据_workflow.xlsx --industry tin --dry-run
python scripts/ai_assisted_curation.py --input output/锡产业链数据_workflow.xlsx --industry tin
```
