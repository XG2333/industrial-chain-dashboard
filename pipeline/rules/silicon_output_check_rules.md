# 硅产业链输出检查规则 (check_silicon_output.py)

## 用途

Workflow 最后一步，验证最终输出文件无分类和筛选缺陷。发现问题将使 workflow 失败。

## 检查项

### 目录表头
必须等于：`#` / `Sheet Name` / `Freq` / `Col` / `Indicator Name` / `Unit` / `板块` / `大类` / `子类` / `数据性质` / `是否选中` / `状态说明`

### 伪指标
名称 = `指标名称` 且单位 = `单位` 的行视为伪指标。

### 合法分类组合
`大类/子类` 必须为以下之一：
- 价格：现货价格、期货价格、月差、现货价差、持仓、成交量
- 成本利润：成本、利润
- 库存：库存、仓单、库存天数、库存指数
- 供给：产能、产量、开工率、数量
- 需求：需求、销量
- 进出口：进出口
- 平衡：平衡
- 其他：宏观、参数、其他

### 分类与规则一致性
每条指标的分类必须与 `reclassify_silicon.classify_row` 的结果一致。

### 单位冲突检测
- 需求/进出口/库存/平衡 大类不允许带价格单位
- 价格/现货价格、价格/期货价格 必须带价格单位（或 手/None）

### 选中状态
`是否选中` 必须为 `是` 或 `否`。
