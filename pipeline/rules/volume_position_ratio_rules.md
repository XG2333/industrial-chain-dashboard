# 成交持仓比计算公共规则

本规则适用于锂电、锡、硅以及后续新增产业链，不按产业区分。

## 触发条件

产业筛选完成后，对最终保留的成交量与持仓量执行配对检查：

- 同一产品、同一合约、同一频率下同时存在选中的成交量和持仓量；
- 该产品/合约尚未存在对应的 `成交持仓比` 指标；
- 持仓量数值大于 0，且成交量、持仓量日期可对齐。

满足条件时计算：

```text
成交持仓比 = 成交量 / 持仓量
```

## 输出

计算结果写入 `成交持仓比计算` Sheet，并在目录 Sheet 追加一条指标：

```text
大类：价格
子类：成交持仓比
数据性质：比率
是否选中：是
状态说明：确定性成交持仓比计算
```

## 实现位置

- `scripts/volume_position_ratio.py`
- `scripts/apply_industry_selection.py`
- `scripts/selection_utils.py`

## 前端展示同步

- 价格大类中的“成交量、成交、持仓、持仓量、成交持仓比”统一显示为“成交持仓”复合组。
- 同一指标的成交量、持仓、成交持仓比相关图放在同一行，行内顺序固定为：成交量 -> 成交 -> 持仓 -> 持仓量 -> 成交持仓比。
- 指标类别导航只显示“成交持仓”一个按钮，不展开各子类按钮。
