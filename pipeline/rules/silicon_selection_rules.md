# 硅产业链筛选规则

## 用途

本文件用于确定目录 Sheet 中每条指标 `是否选中`。筛选在分类完成后执行，输入为大类和子类已经确定的目录。

当前实现位于：

- `scripts/silicon_selection_rules.py`
- `scripts/apply_silicon_selection.py`

## 价格

- `价格 / 期货价格`：只保留主力合约、01合约、05合约、09合约。
- `价格 / 持仓`：只保留主力合约、01合约、05合约、09合约。
- `价格 / 月差`：只保留 01-05、05-09、09-01。
- `价格 / 现货价差`（含基差）：基差只保留当月合约或现货升贴水；其他价差全部保留。
- `价格 / 成交量`：只保留主力合约、01合约、05合约、09合约。
- `价格 / 成交持仓比`：全部保留。
- `价格 / 现货价格`：当前规则下只做分类，不自动选中；如需保留，应增加“现货价格按日度/周度/月度保留”的规则。

## 成本利润

- 同一指标存在多个频率时，只保留最高频；该规则覆盖成本利润大类下所有子类。
- 同一指标同频重复时，只保留一条。
- 最高频判断优先使用标题中的频率后缀，再回退到目录 `Freq`。
- 频率优先级：日度 > 周度 > 月度 > 季度 > 年度。
- 指标名称同时含“年化”和其他日/周/月/季/年频率词时，按年度处理。

## 库存

- `库存 / 仓单`：只保留分仓库日度数据，或期货总仓单。
- 其他 `库存`：只保留周度和月度。

## 供给

- `供给 / 产量`、`供给 / 产能`、`供给 / 开工率`、`供给 / 数量`：只保留日度、周度、月度。

## 需求

- `需求 / 需求`、`需求 / 销量`：只保留日度、周度、月度。

## 进出口

- 只保留总量月度数据。
- `进出口 / 进口`、`进出口 / 出口`、`进出口 / 净出口`：只保留月度总量。
- 只保留同时存在总量月度进口和出口的指标；只有进口没有出口，或只有出口没有进口的指标一律筛除。
- 成对指标缺失净出口时，按公共规则计算 `净出口 = 出口 - 进口`。
- 分国别、分规格、均价、非总量数据不选中。

## 平衡

- `平衡 / 平衡`：只保留日度、周度、月度。

## 其他

- `其他 / 宏观`、`其他 / 参数`：当前规则下默认不选中。

## 检查

工作流最后会执行 `scripts/check_silicon_output.py`，检查分类是否与规则一致、是否存在伪指标、是否存在明显的大类/单位冲突。
## 数量平衡硬校验

进出口总量标题可能写作 `进口量/出口量/进口额/出口额`，也可能直接写作
`进口/出口/净出口`。最终产业筛选必须处理全部目录行，不能只依赖 Skill2
预先选中的结果；只要同一口径存在月度进口和出口，就应保留进口、出口以及
对应净出口，并筛除其余重复或聚合行。

每次 `apply_industry_selection.py` 保存前必须校验：`进出口` 大类下
`进口`、`出口`、`净出口` 三个子类的选中数量必须相等，否则流程直接失败。
