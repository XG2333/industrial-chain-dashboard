## 一、锂电产业链

### 1. 锂矿

建议顺序：`lithium_resource → lithium_mining → concentrate_trade → ore_balance`

- node_1：资源储量
  - node_name: `lithium_resource`
  - node_rank: 1
  - confidence: high
  - reason: 储量、自给率是锂矿资源端的起点，先于采选和贸易。
  - matched_indicators: 锂矿储量、锂资源自给率类指标（供给/储量、供给/自给率）
- node_2：采选产量
  - node_name: `lithium_mining`
  - node_rank: 2
  - confidence: high
  - reason: 从资源到可流通精矿的加工环节，产量和开工决定供给。
  - matched_indicators: 锂矿/锂精矿产量、开工率类指标（供给/产量）
- node_3：精矿价格与贸易
  - node_name: `concentrate_trade`
  - node_rank: 3
  - confidence: high
  - reason: 精矿进口/出口、进口均价、港口库存是资源向锂盐输送的流通节点。
  - matched_indicators: 中国海关锂精矿月度进口均价、锂辉石进口均价、锂矿库存天数/库存指数、锂矿进出口
- node_4：供需平衡
  - node_name: `ore_balance`
  - node_rank: 4
  - confidence: medium
  - reason: 平衡指标用于校验全环节，适合放在板块末尾。
  - matched_indicators: 锂矿供需平衡类指标

`需求/出货量` 已按当前分类规则归入“需求”大类，但锂矿节点映射暂未单独分配。

## 四、汇总

### 1. 一级板块建议内部节点数

- 锂电：锂矿 4、碳酸锂 4、氢氧化锂 4、其他锂盐 3、三元正极 3、磷酸铁锂 4、钴酸锂 3、锰酸锂 3、负极材料 4、隔膜 3、电解液产业链 3、辅材 3、电池电芯 4、储能 4、新能源汽车 3、磷化工链 3、其他 0
- 锡：锡矿 4、锡锭 3、锡材 3、锡期货 3、锡其他 1、铅蓄电池 3、镀锡板 3
- 硅：硅石石英砂 2、硅基原料 2、工业硅 4、多晶硅 4、有机硅 3、硅片 3、电池片 3、组件 3、光伏辅材 1、下游需求 2、铝合金 1

### 2. 各板块建议顺序

已在各板块小节/表格中给出，核心链路为：

```text
资源/原料 → 中间品 → 产品/价格 → 库存/贸易 → 平衡/需求
```

### 3. 明显存在上下游关系的板块

- 锂矿 → 碳酸锂/氢氧化锂 → 正极材料 → 电芯 → 储能/新能源汽车
- 磷化工链 → 磷酸铁锂
- 三元正极：前驱体 → 正极材料
- 磷酸铁锂：原料 → 磷酸铁 → 磷酸铁锂
- 负极材料：石墨原料 → 石墨化 → 负极成品
- 隔膜：基膜 → 涂覆膜
- 电解液：原料/添加剂 → 电解液成品
- 硅：硅石 → 工业硅 → 多晶硅 → 硅片 → 电池片 → 组件 → 下游需求
- 锡：锡矿 → 锡锭 → 锡材/铅蓄电池/镀锡板

### 4. 不适合按上下游排序的板块

- 其他锂盐、辅材：产品类型差异大，建议按产品类型分组。
- 锡其他、锡期货：分别为化工产品池和期货合约，无产业链上下游。
- 光伏辅材、铝合金：建议按产品类型或市场/PMI 指标排。
- 下游需求、新能源汽车：更适合按需求/市场类型排。

### 5. 需要人工确认

1. 负极材料板块内的 `SMM 1#电解铜` 是否应归入铜箔/辅材。
2. 其他锂盐中 NMP/CMC/SBR 与锂盐的板块归属。
3. 磷酸铁锂“修复型/回收型”产品节点是否单独拆分。
4. 储能中政策/招标/中标与装机的先后顺序。
5. 锡材中锡合金与锡材的边界。
6. 硅片工序参数类指标应并入哪个工序节点。
