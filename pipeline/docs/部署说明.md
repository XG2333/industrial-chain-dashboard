# 产业看板系统部署说明

本包整合了**数据处理管道（多skill联动 + Selecting skill）**与**前端看板（本地可视化dashboard）**
的全部处理脚本、规则文本与配置（不含任何产业数据）。在另一台电脑上放置**原始产业数据**后，
一键运行 skill 管道即可复现与当前完全一致的前端看板。

## 包结构

```
产业看板系统/
├── 部署说明.md              ← 本文档
├── requirements.txt         合并后的 Python 依赖（三项目）
├── data/                    看板数据输出目录（process_all.py 自动生成）
├── 多skill联动/             数据处理管道（skills / scripts / rules / 排序规则.md / process_all.py / tests）
├── Selecting skill/         Skill1 规则源（selection_rules.docx 等，workflow 依赖）
└── 本地可视化dashboard/      看板前后端（server.py / frontend/ / docs/ / .env.example / start.bat）
```

## 新电脑部署（三步，无需手动装环境）

> 需要网络（首次自动下载 Python/Node.js 与依赖包）；若电脑已装 Python 3.11+ / Node 18+ 则直接复用。

### 第 1 步：放置原始产业数据

把**原始未处理**的产业数据放入 `多skill联动\input\`：

| 原始文件 | 对应行业 |
|---|---|
| 碳酸锂数据库.xlsx | 锂电 |
| 锡产业链数据.xlsx | 锡 |
| 硅产业链数据.xlsx | 硅 |

> **样例数据（演示/试跑）**：部署包自带 `多skill联动\input\样例\` 下三份**样例源文件**
> （结构与真实源一致，数值全随机，不含任何真实数据，由
> `多skill联动\scripts\generate_sample_source_data.py` 生成）。
> 无真实源数据时，把 `input\样例\*.xlsx` 复制到 `input\` 根目录即可跑通
> Skill1-4 全流程并启动看板；有真实源数据后替换同名文件即可（流程不感知内容差异）。

### 第 2 步：双击 `setup.bat`（一键配置环境）

自动完成：检测/安装 Python（winget）→ 创建 .venv → 安装 Python 依赖 →
检测/安装 Node.js（winget）→ npm install + 前端构建 → 生成并配置 .env
（自动写入 STOCK_TARGETS_DIR、清空 WORKFLOW_CURRENT_PATH）。

> 无 Python/Node 时自动静默安装；winget 不可用时脚本会提示手动安装地址。

### 第 3 步：双击 `run_all.bat`（一键处理并启动看板）

自动完成（每行业）：
1. **run_industry_pipeline**：Skill1-4 workflow（目录生成→财务变量筛选→净出口→复合指标→标记→筛选）
   + 产业校准 → 频率校验 → 分类一致性 → 行业筛选 → **板块一级排序**（sort_catalog）
2. **二次筛选列**生成（锂电专属规则 / 锡硅通用规则）
3. **个股标的**生成（stock-target-curator，纯配置，无需 AI）
4. 产物复制到 `本地可视化dashboard\data\` + 清理缓存
5. 启动看板并打开 http://127.0.0.1:8000

> 处理默认 `--provider mock`（确定性规则，无需 API Key）；如需 AI 辅助整理，
> 可改用命令 `python process_all.py --ai`（需配置 DEEPSEEK_API_KEY）或 `--only <行业>` 单行业处理。
> 某行业原始文件缺失时自动跳过，不阻塞其余行业。

## 手动分步（可选，替代一键脚本）

- 环境：`python -m venv .venv && .venv\Scripts\python -m pip install -r requirements.txt`
- 全流程管道（单行业）：`.venv\Scripts\python 多skill联动\scripts\run_industry_pipeline.py --industry <lithium|tin|silicon> --input <原始文件> --output <目标>`
- 二次筛选列：锂电 `recompute_secondary_only.py <输入> <输出>`；锡/硅 `recompute_secondary_tin_silicon.py`
- 个股标的：`.venv\Scripts\python 多skill联动\skills\stock-target-curator\scripts\generate_stock_targets.py --industry <x> --output <个股标的_x.xlsx>`
- 手动启动：`cd 本地可视化dashboard && ..\.venv\Scripts\python -m uvicorn server:app --host 127.0.0.1 --port 8000`
